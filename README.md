# 保育士Pass プライバシーポリシー

最終更新日: 2026年6月19日

保育士Pass（以下、「本アプリ」）は、ユーザーのプライバシーを尊重し、個人情報の適切な取り扱いに努めます。本プライバシーポリシーは、本アプリにおける情報の収集・利用・管理方針について説明するものです。

## 1. 本アプリ内で保存する情報

本アプリでは、学習機能を提供するため、以下の情報をお使いの端末内に保存します。

- 問題への回答履歴、正誤記録
- 苦手フラグ
- 文字サイズ設定
- 合格済み科目の登録情報
- 連続学習日数
- 広告視聴による当日追加解放の状態

これらの学習データは、原則としてお使いの端末内に保存されます。本アプリは、氏名、住所、電話番号、メールアドレス、連絡先、正確な位置情報をアカウント情報として独自に取得しません。

## 2. 第三者サービスの利用

本アプリでは、広告配信、アプリ内課金、利用状況分析のために以下の第三者サービスを利用します。

### Google AdMob

無料ユーザー向けに広告を表示するため、Google AdMobを利用しています。AdMobでは、広告配信や不正利用防止のため、端末情報、広告識別子、IPアドレス、アプリの利用状況などが処理される場合があります。

本アプリでは、広告IDやFirebaseのデータを、他社のアプリやWebサイトをまたいだトラッキング目的で利用しません。

- Google プライバシーポリシー: https://policies.google.com/privacy

### RevenueCat

アプリ内課金の管理にRevenueCatを利用しています。RevenueCatでは、購入状態の確認、購入履歴の復元、プレミアム機能の有効化のため、匿名のユーザーIDや購入状態に関する情報が処理される場合があります。

- RevenueCat プライバシーポリシー: https://www.revenuecat.com/privacy

### Firebase Analytics

本アプリでは、アプリの利用状況を把握し、学習体験や機能品質を改善するために、Google LLC が提供する Firebase Analytics を利用します。

Firebase Analytics では、アプリの起動、学習モードの利用、科目ID、正誤、学習セッション完了、模試結果のスコア帯、課金画面の表示元、購入フロー、レビュー依頼候補トリガーなど、アプリの利用状況に関するイベントを送信することがあります。

Firebase Analytics には、問題本文、選択肢本文、解説本文、自由入力、記述答案、氏名、メールアドレス、個別相談内容、問題ID、RevenueCat app_user_id、Apple の決済識別子の生値、RevenueCat SDK Key、AdMob ID、公式問題本文や出題文を復元できる情報を送信しません。

Firebase Analytics により収集される情報は、Google のプライバシーポリシーおよび Firebase の規約に従って取り扱われます。

- Google プライバシーポリシー: https://policies.google.com/privacy
- Firebase におけるプライバシーとセキュリティ: https://firebase.google.com/support/privacy

## 3. 利用していないFirebaseサービス

本アプリでは、Firebase Analytics のみを利用します。以下のFirebaseサービスは利用していません。

- Firebase Authentication
- Firestore
- Realtime Database
- Cloud Functions
- Storage
- BigQuery export
- Firebase AI Logic
- Remote Config
- Crashlytics
- App Check
- Cloud Messaging

## 4. 情報の利用目的

本アプリで保存または第三者サービスを通じて処理される情報は、以下の目的にのみ利用します。

- 学習進捗の管理と表示
- 科目別分析、ニコイチ科目の進捗表示
- 文字サイズなどのアプリ設定の保持
- 広告の配信
- アプリ内課金の管理
- アプリの利用状況分析、品質改善、機能改善
- 不正利用防止、障害調査

## 5. 情報の第三者提供

本アプリは、法令に基づく場合を除き、ユーザーの情報を第三者に販売しません。第三者サービスを利用する場合は、各サービス提供者のプライバシーポリシーおよび利用規約に従って情報が処理されます。

## 6. 情報の削除

学習データは、アプリ内の「設定」からリセットできます。アプリをアンインストールすることで、端末内に保存された本アプリのローカルデータも削除されます。

ただし、App Storeの購入履歴、RevenueCatが管理する購入状態、Google AdMobやFirebase Analyticsなど第三者サービス側で処理された情報は、各サービスのポリシーに従って管理されます。

本アプリは、保育相談、育児相談、保育施設紹介、就職支援、診断、個別助言サービスを提供するものではありません。

## 8. 未成年者の利用について

本アプリは特定年齢層を対象とした利用制限は設けていませんが、未成年者が利用する場合は保護者の同意のもとでご利用ください。

## 9. プライバシーポリシーの変更

本プライバシーポリシーは、法令の改正やサービス内容の変更に応じて予告なく改定する場合があります。改定後のポリシーは本ページに掲載した時点から効力を生じるものとします。
